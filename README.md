# Hippo House V1

Front-end sales/presentation page for Hippo House — 4 Bedroom Jomtien Beach.

## Included
- Responsive desktop/mobile layout
- Uses only the real property photos supplied for this project
- Hero / highlights / gallery / floor details / amenities / location / booking CTA
- Gallery lightbox
- Floor tabs
- Google Maps link
- Static site, ready for GitHub Pages

## Before publishing
Replace the V1 booking CTA behavior in `assets/main.js` with the real booking channel:
- LINE OA
- WhatsApp
- Phone
- Booking form

## GitHub Pages
Upload all files in this folder to the root of a repository, then:
Settings → Pages → Deploy from a branch → main / root.
